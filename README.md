# MDLive

A markdown editor with a live preview.

## Features

- Side-by-side editor and rendered preview
- Toolbar for headings, lists, links, code and more
- Download as .md or copy the generated HTML
- Your document is saved automatically

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
